## 운영·안전 검토

- [ ] 소유/허가 대상만 사용했는가?
- [ ] 실제·데모·사례 자료가 합쳐지지 않았는가?
- [ ] UID·SSID·BSSID·위치·실명 등 재식별 단서를 가명 처리했는가?
- [ ] 과열·배터리 부족·권한 불명확·복구 불가 시 중단했는가?
- [ ] 재밍·재전송·자격 증명 수집·타인 네트워크 접속을 시도하지 않았는가?
- [ ] 원본 CSV는 보존하고 분석본을 새 파일로 만들었는가?

## 판정·인계

파일럿 통과는 `완주 기준`, 실제 분모, 관찰·복구 증거, 실패 대안, 교사 개선안이 모두 채워진 경우에만 검토한다. 장비 없이 진행한 사례 활동은 **대체 경로 통과**로 별도 표시한다.
