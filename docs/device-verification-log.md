# 실기기 검증 기록

상태: **미검증 템플릿**. 빈칸은 미확인 상태이며, 화면·파일·실제 조작을 확인하기 전에는 `기기 verified`로 바꾸지 않는다. 웹 페이지가 열리는 것(`웹 ready`)과 실기기 동작 확인, 교실 파일럿 통과(`교실 파일럿 passed`)는 서로 다른 상태다.

## 기록 원칙

- 소유하거나 사용 허가를 받은 기기·태그·공유기만 확인한다.
- 화면에 없는 패킷·수치·성공을 추정하지 않는다. 값이 없으면 `미관찰`, `미측정`, `확인 안 됨` 중 하나로 남긴다.
- 한 번의 성공이나 메뉴 표시만으로 전체 기능을 검증했다고 쓰지 않는다.
- 원본 사진·로그·내보낸 파일의 경로를 남기되, UID·SSID·BSSID·위치·실명은 가명 처리한다.

## 검증 판정

- 웹: `사용 가능 / 부분 사용 / 미완료` — 페이지·입력·백업·복구를 브라우저에서 확인했는가?
- 기기: `verified / 부분 확인 / 미검증` — 실제 펌웨어·메뉴·출력·복구 증거가 있는가?
- 교실: 이 문서만으로 판정하지 않는다. 학생 모둠 파일럿은 별도 `classroom-pilot-log.md`에 기록한다.
