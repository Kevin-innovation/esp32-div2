# 사이트 공통 현재 위치 표시와 링크 인지성

기준: fabfb84. 감사 결과는 네 가지다.

- 지금 읽는 절 표시(scrollspy)는 Python 과정 8차시의 CourseBar에만 있다. 보안, NFC, 네트워크 같은 일반 학습, 기능 가이드, 13개 워크북 목차에는 없다.
- 목차 hover의 초록 밑줄이 현재 위치처럼 보인다.
- 전역 `a`가 검정 600 굵기에 매우 연한 회색 밑줄이라 `strong`과 구별되지 않는다.
- 용어 사전 링크, 관련 실습 링크, 외부 출처 링크의 생김새가 서로 비슷하다.

새 의존성, 플랜 프레임워크, 진도 저장은 없다. 교육 내용, 저장, URL은 그대로 둔다.

## P1 공통 위치 추적

**적용 범위**는 목차(`[data-toc]`)가 있는 모든 페이지다.

| 목차 | 쓰는 곳 |
|---|---|
| LearnLayout `.toc` | 학습 7장, 기술노트, Python 과정 8차시 |
| `.toc` 직접 작성 | 시작, 업데이트, 기능 가이드 묶음 |
| LabGuide `.wb-toc` | 워크북 13개 |

**태스크**

1. `src/lib/tocSpy.ts` 한 곳에서 계산한다.
   - 스크롤, resize, hashchange, load, 본문 ResizeObserver(코드·접힘 펼침에 따른 reflow)를 받아 rAF로 한 번만 계산한다.
   - 기준선은 실제로 붙어 있는 머리글·학습 바·진행바·절 바의 아래 끝 + 24px에, 대상의 `scroll-margin-top`(워크북 장 16px)을 더한 값이다.
   - 현재 절은 주소(hash)가 아니라 실제 스크롤로 정한다. 페이지 끝에서는 화면에 보이는 마지막 절을 고른다.
   - 예외는 하나다. 링크나 #앵커로 막 이동한 뒤 스크롤 위치가 그대로이고 그 절이 화면에 있으면 그 절을 고른다(더 내려갈 수 없는 짧은 끝 절을 눌렀을 때). 조금이라도 스크롤하면 이 예외는 풀린다.
   - 목차 링크에 `aria-current="location"`을 단다. CourseBar도 같은 상태를 구독하고, 자기 스크롤 계산은 지운다.
2. 붙은 바의 실측 높이로 `--toc-offset`을 정한다. `scroll-padding-top`은 이 값에 16px을 더한다(JS가 꺼지면 기존 8rem과 4.5rem).
   - #앵커로 처음 들어오면 그 값으로 한 번 다시 맞춘다.
   - 뒤로 가기에서는 브라우저가 복원한 위치를 두고, URL과 history는 바꾸지 않는다.
3. 현재 목차는 초록 옅은 바탕, 왼쪽 3px 초록 선, 굵게 표시한다. hover는 회색 바탕만 쓰고 초록을 쓰지 않는다. focus는 공통 외곽선이다.
   - 현재 항목이 목차 상자 밖에 있으면 상자 안에서만 스크롤한다. 본문은 움직이지 않는다.
4. 모바일(60rem 이하, JS 켬)에서는 목차 페이지에 절 바 하나만 붙인다. 바 높이는 48px이고, 토글과 패널 링크의 누름 영역은 44px 이상이다.
   - 절 바에는 목차 이름, "지금 절", 펼침 표시가 있다. 이 페이지에서는 기본 학습 바를 붙이지 않고 제자리에 둔다. 그래서 고정 요소는 절 바 하나만 남는다.
   - 펼치면 목차 전체가 나오고 현재 절이 표시된다. 본문 위의 정적 목차는 숨긴다.
   - Escape는 닫고 초점을 되돌린다. 밖을 누르거나, 초점이 나가거나, 링크를 눌러도 닫힌다.
   - Python 과정은 기존 CourseBar가 이 역할을 한다.
5. JS가 꺼지면 기존 정적 목차와 링크가 그대로 동작한다.

**인수 조건**

- 스크롤 위·가운데·아래에서 현재 목차가 하나이고, 문서 기준 계산과 같다.
- #앵커로 들어와도 제목이 바에 가리지 않는다. 뒤로 가기, 코드 펼침으로 인한 reflow, 페이지 끝의 짧은 절에서도 표시가 맞다.
- hover 상태와 현재 상태의 계산된 스타일이 다르다.

## P2 링크와 이동 영역

1. **본문 링크**(`.doc__main`, `.wb-main`, 학습 끝 카드 안의 class 없는 `a`)
   - 처음부터 초록 글자와 보이는 실선 밑줄로 표시한다. 색만으로 구분하지 않는다.
   - hover는 밑줄을 2px로 굵게 하고, active는 먹색으로 바꾼다.
   - 굵기 500으로 `strong`(먹 600, 밑줄 없음)과 구별한다.
   - 양 테마에서 바탕 대비 4.5:1 이상이다.
   - 버튼, 상단 메뉴, 목차, 그림 핀, 카드처럼 class가 있는 링크는 각자 스타일을 유지한다.
2. **용어 사전 링크**는 점선 밑줄과 ⓘ를 유지한다. ⓘ와 hover 바탕을 더 분명하게 한다.
3. **외부 링크**
   - 본문 안의 외부 링크 뒤에는 작은 ↗(화면 읽기 "외부 사이트")를 붙인다.
   - 출처 목록과 근거 자료 목록은 제목이 이미 맥락을 주므로 붙이지 않는다.
   - 기존 `rel`과 `target`은 그대로 둔다.
4. **관련 실습 행**(`.go-list`)
   - 보안 "실험 연계"를 쉼표로 이은 글자에서 행으로 바꾼다. 행마다 도착 페이지 이름, 제목, 화살표가 있고 높이는 44px 이상이다.
   - 카드 안의 카드와 알약 묶음은 쓰지 않는다.
5. **상태**: focus-visible은 공통 외곽선이 바로 보인다. 움직임 줄이기에서는 화살표가 움직이지 않는다.
