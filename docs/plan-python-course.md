## 3. 학습 사다리와 파일

각 단계: 설명 → 예제 보기(실행) → 빈칸 완성(`___`, 힌트) → 빈 셀 직접 작성(확인 셀) → 정답과 이유(접힘) → 오류·함정 예 → 변형 문제 → 원본 미션 원문 줄로 돌아가기.

- 빈칸은 `___`로 쓴다. 채우지 않고 실행하면 `NameError: name '___' is not defined`가 나는 것이 정상이며 페이지와 파일 머리말에 적는다.
- 직접 작성 칸은 `raise NotImplementedError(...)`로 비워 둔다.
- 확인 셀은 정답과 독립된 assert이며 통과하면 `확인 통과`를 출력한다.
- 차시마다 학생용 틀.py, 교사용 완성.py, 예상 출력.txt를 내려받을 수 있다. 학생용 틀은 그대로 실행되지 않는다고 안내한다.

## 5. 완료 조건

- 새 페이지 6개(2~6, 8차시)에 실제 내용. 기존 URL과 앵커 유지.
- 모든 예제·빈칸 정답·직접 작성 정답·함정·변형 코드를 실제 Python으로 실행해 예상 출력을 저장하고 대조한다.
- 빈칸 코드는 NameError, 직접 작성 틀은 NotImplementedError, 확인 셀은 정답 없이 실패하고 정답과 함께 통과한다.
- 학생용 틀 파일은 실패, 교사용 완성 파일은 끝까지 실행된다.
- 6차시 결과가 NFC 미션 9장 검증용 JSON과 같다. 8차시 BLE 전이 과제 정답이 BLE 미션 결과와 같다.
- NFC 원문 영역을 이어 붙이면 원문과 같고, 실행 출력이 9장 예상 출력과 같다.
- 13개 미션과 노트북의 모든 호출 이름이 함수 사전에 있다.
- 13개 미션 9장에 관련 차시와 그 미션 코드 지도로 가는 직링크가 있다.
- typecheck, build, check-nav, 375·1280 양 테마 넘침·콘솔 0.
