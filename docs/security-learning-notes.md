# 정보보호 학습 노트

정보보호학과 진학을 생각하는 고등학생을 위한 활동 기록 문서입니다. 자세한 설명은 웹의 `/learn/security/`에 있고, 이 문서는 목표와 기록 양식을 담습니다. 복사해 내 공책처럼 쓰세요.

이 노트의 위협은 각 기술에 일반적으로 알려진 내용입니다. 이 기기에서 찾아낸 취약점이 아닙니다. 다른 사람의 망, 기기, 카드는 대상으로 삼지 않습니다.

## 학습 목표

- 자산, 공격자, 접근 범위, 신뢰 경계, 피해로 위협 모델을 쓴다.
- 취약점, 위협, 위험을 구별한다.
- 기술별로 왜 약해지는지와 방어의 한계를 함께 말한다.
- 직접 확인한 것과 문서로만 아는 것을 나눠 보고한다.

## 활동 기록 양식

활동마다 아래를 복사해 씁니다.

```markdown
### 활동 이름:

- 날짜:
- 대상 (내 것인지 확인):
- 내가 한 일:
- 직접 본 것:
- 문서로만 아는 것 (출처):
- 알게 된 자산과 위협:
- 방어와 그 한계:
- 하지 않은 일:
- 다음 질문:
```

## 위협 모델 양식

```markdown
- 자산:
- 공격자와 목적:
- 접근 범위:
- 신뢰 경계:
- 피해:
- 현재 약점:
- 고친 설계:
- 고친 뒤에도 남는 위험:
```

## 진로 연계 요약

- 수학: 확률, 지수, 로그
- 물리: 파동, 전자기 유도
- 정보: 파이썬, 데이터 분석
- 전공 기초: 네트워크, 운영체제, 암호, 보안 설계

활동 기록과 자소서에는 직접 한 활동, 쓴 근거, 그 뒤 달라진 생각을 씁니다.
